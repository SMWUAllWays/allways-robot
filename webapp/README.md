# All Ways web app

숙명여자대학교 교내 이동을 위한 접근성 경로 추천 화면입니다. 기존 로봇 제어 코드는 그대로 두고 `webapp/`에 분리했습니다. 제공된 숙명여대 캠퍼스 조감도를 건물 배치 참고 화면으로 사용합니다.

## 실행

저장소 루트에서 로컬 서버를 실행한 뒤 `http://localhost:8000/webapp/`을 여세요.

```powershell
python -m http.server 8000
```

## 실제 Google 지도 연결

1. Google Cloud 프로젝트에서 Maps JavaScript API와 Geocoding API를 사용 설정하고 API 키를 발급합니다. Google 문서상 두 API 사용에는 billing 계정이 필요합니다.
2. 키는 이 두 API만 허용하고, 웹사이트 제한에 개발용 `http://localhost:8000/*`와 배포 도메인을 지정합니다. Google 지도는 브라우저에서 키를 사용하므로 저장소에 키를 넣지 마세요.
3. 앱 우측 상단 설정에서 키를 입력합니다. 키는 이 브라우저의 localStorage에 저장됩니다.

학교가 공식으로 안내하는 주소는 `서울특별시 용산구 청파로47길 100`입니다. 기본 지도 중심 좌표는 학교 오시는 길 페이지의 Google 지도 링크에서 확인한 `37.546475, 126.9646916`이며, 화면 이동은 `CAMPUS.bounds`의 직사각형 범위(`north 37.5521`, `south 37.5408`, `west 126.9568`, `east 126.9726`)로 제한합니다. 이 범위는 캠퍼스 주변을 보여주기 위해 정한 화면 범위이며, 학교 부지의 공식 경계선은 아닙니다. 건물 위치는 학교 이름을 기준으로 Google Geocoding API에 조회하고, 제한 범위 안에 반환된 결과만 지도에 표시합니다.

지도 바탕과 건물 위치는 Google 지도 데이터를 사용합니다. 경로 계산은 이 앱의 구간 데이터를 이용합니다. 지금의 구간 연결선, 거리, 통로 폭, 경사, 계단 및 장애물 표시는 인터페이스 시연용 값입니다. 실제 로봇 측정 결과나 검증된 보행로를 뜻하지 않습니다. Google의 보행 경로 또한 보행로가 누락될 수 있다고 안내되어 있어, 접근성 정보 없이 경로선만 믿고 실제 이동에 사용해서는 안 됩니다. 실제 시연 전에는 팀의 현장 조사와 로봇 센서 데이터로 `CAMPUS.edges`를 교체해야 합니다.

학교 건물 이름과 번호는 학교 공식 캠퍼스 안내 및 장애학생지원센터의 편의시설 안내도에 따릅니다.
